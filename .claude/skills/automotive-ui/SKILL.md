# Premium Automotive UI Skill — Vaccino

Use for landing page changes, showcases, showroom UX, Driver visualizations, interaction design and Nextion demo screens.

## Sequence
1. Read `AGENTS.md`, `docs/PROJECT_CONTEXT.md` and `docs/DESIGN_SYSTEM.md`.
2. Inspect the exact HTML/CSS/JS being changed and identify reused components.
3. Produce a concise interaction concept before implementation, with user-visible acceptance criteria.
4. Build the smallest polished working vertical slice; reuse existing assets and 3D pipeline.
5. For every new UI state, include keyboard/mobile support and accessible semantics.
6. Verify with running site and screenshots at desktop and mobile sizes.
7. Explicitly note what is illustrative, and do not invent product compliance or mechanical engineering results.
8. Deliver changed files, preview route, test results, and remaining defects.

## Visual design rubric
- Vehicle and driver visuals lead; typography acts as supporting editorial voice.
- Keep premium spacing, hierarchy and restrained gold.
- Avoid dashboard overload and generic templates.
- Test element collision, 3D controls and overlays with real browser interaction.
- Preserve the site's existing working features and source data.

## Not this skill's job
- Production-ready chassis CAD, FEA or regulated PPE certification.
- Public publication without approval.
